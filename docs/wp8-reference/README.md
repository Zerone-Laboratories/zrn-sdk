# Windows Phone 8 reference

zrnui follows the Windows Phone 8 Silverlight controls. The reference material
itself is Microsoft's and is not kept in this repository:

- **API reference**: the IntelliSense XML of the Windows Phone 8 SDK
  (`wpsdk_en.cab` in the SDK installer), and the Windows Phone Toolkit sources
  at github.com/microsoftarchive/WindowsPhoneToolkit.
- **Theme resources and control templates**: the `Design` folder of the SDK
  (`ThemeResources.xaml`, `System.Windows.xaml`, the accent colour files) and
  the WP 7.1 `generic.xaml`.
- **ApplicationBar icons**: the `Icons` folder of the SDK.
- **Segoe WP fonts**: Microsoft-licensed; zrnui ships Selawik instead.

Kept here:

- [themes.md](themes.md): the theme constants zrnui uses (accent colours,
  Dark and Light colours, font sizes, margins, text styles).
